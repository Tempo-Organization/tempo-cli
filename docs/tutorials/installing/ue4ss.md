# UE4SS

[UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) is an Unreal Engine scripting and modding framework that provides Lua scripting, SDK generation, dumping utilities, and other tools for Unreal Engine 4 and 5 games.

There are two main ways to install UE4SS: using [**UE4SS Installer GUI**](https://github.com/Mythical-Github/ue4ss_installer_gui) or installing it manually.

### UE4SS Installer GUI

The recommended option is to use [**UE4SS Installer GUI**](https://github.com/Mythical-Github/ue4ss_installer_gui). The installer can detect games, select UE4SS versions and releases, and install or uninstall UE4SS automatically. It also supports filtering releases by version, developer builds, prereleases, and other options.

[**Download UE4SS Installer GUI**](https://github.com/Mythical-Github/ue4ss_installer_gui/releases)

It is recommended to install the latest experimental release of UE4SS. These releases contain the newest changes from UE4SS and can provide fixes, improvements, and more before they reach a stable release.

### Manual Installation

To install UE4SS manually download an [UE4SS release](https://github.com/UE4SS-RE/RE-UE4SS/releases) and extract its contents into the game's executable directory, usually:

```text
<Game Directory>/<Game Name>/Binaries/Win64/
```
