# Unreal Engine

Installing Unreal Engine is usually done through the **Epic Games Launcher**. This is the recommended option for most users.

[**Download Unreal Engine through the Epic Games Launcher →**](https://www.unrealengine.com/download)

Alternatively, you can build Unreal Engine from source. To do this, you need to link your Epic Games account with GitHub and join the **Epic Games organization on GitHub**, which gives you access to the Unreal Engine source repository.

[**Get access to Unreal Engine on GitHub →**](https://www.unrealengine.com/ue-on-github)

For some games, the developers or modding communities may also provide **pre-built or modified Unreal Engine releases on GitHub**. These can be useful when a specific game requires a particular engine version or custom engine modifications..

### Which Version Should I Use?

For most projects, use the **official version from the Epic Games Launcher** unless you specifically need:

- A particular Unreal Engine version that is not available through the launcher.
- The ability to modify or compile the engine yourself.
- A game-specific or community-provided engine build.
- Engine modifications required by a particular game or modding project.

When working with an existing game or modding project, **the engine version used by the game should generally be matched as closely as possible**. Using a different engine version can cause compatibility, packaging, or asset issues.
